# 🚢 Battleship Android Game

A mobile adaptation of the classic **Battleship** strategy board game built for Android. This project was developed as part of the **COMP 319A (Mobile Application Development)** coursework at Koç University.

---

## 🎮 Game Overview

The objective is to locate and sink all hidden enemy ships on a grid before the opponent sinks yours. Players take turns firing shots at coordinate points on the board, receiving feedback for hits, misses, or sunken vessels.

### Key Features
* **Grid-Based Gameplay:** Interactive battle board supporting ship placements and shot tracking.
* **Turn-Based Combat:** Real-time state management between player actions and enemy AI/logic.
* **Game States & Feedback:** Visual cues for hits, misses, sunk ships, and final victory/defeat conditions.
* **Clean UI:** Intuitive mobile layout adapted for touch controls and Android view lifecycles.

---

## 🛠️ Tech Stack & Architecture

* **Language:** Kotlin / Java
* **Platform:** Android SDK (minSdk 24+, targetSdk 34)
* **UI Framework:** Jetpack Compose / XML Layouts
* **Architecture:** MVVM (Model-View-ViewModel) / State Management
* **Build Tool:** Gradle (Kotlin DSL / Groovy)
